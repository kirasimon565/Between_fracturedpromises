# Between: Fractured Promises

interactive story game

## Getting Started

1.  **Install Dependencies:**
    ```bash
    flutter pub get
    ```

2.  **Run the App:**
    ```bash
    flutter run
    ```

## Architecture
- **State Management:** GetX
- **Backend:** Firebase (Firestore, Auth, Storage)
- **Engine:** Custom JSON-based story engine with branching narrative.

## Admin Access
