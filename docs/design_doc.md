# Design Document
## Overview
Between: Fractured Promises is a simulated mobile OS game.

## Themes
- **Safe:** Blue, Messenger-style. Represents public life.
- **Secret:** Red/Dark, Makelove-style. Represents the affair/hidden life.

## Core Mechanics
- Real-time message playback.
- Dual-persona management.
- Admin Dialpad for live ops.
